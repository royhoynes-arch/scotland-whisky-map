# Skottland – whiskydestillerier

Dette er en lett GitHub Pages-versjon uten store utskriftsfiler.

Last opp `index.html` i roten av repositoryet, og `data/destillerier_137.csv` i mappen `data`.

Aktiver GitHub Pages under Settings > Pages > Deploy from a branch > main / (root).

PDF- og PNG-filene til A3-utskrift er bevisst utelatt for å unngå opplastingsgrensen.
